# 🍽️ MessPulse — Frontend Client

This directory contains the React 19 + Vite frontend application for **MessPulse**, featuring a modern Glassmorphism UI, Tailwind CSS v4, and real-time Chart.js dashboards.

For complete system architecture, backend setup, database migrations, environment variables, and production deployment documentation, please refer to the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start Vite dev server with proxy to backend
npm run dev

# Lint code
npm run lint

# Build production bundle
npm run build
```
